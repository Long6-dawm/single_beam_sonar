# 单波束声纳测距系统

基于 STM32F407 的单波束声纳测距系统。系统发射线性调频（LFM）脉冲信号，接收水下回波后经频域匹配滤波（脉冲压缩）提取时延，从而实现水下测距，并通过串口触摸屏实时显示距离。

## 技术指标

- 主控：STM32F407VGT6（Cortex-M4F，168 MHz）
- 发射信号：LFM，中心频率 200 kHz，带宽 10 kHz，脉宽 1 ms
- 波形发生：DAC 以 500 kHz 更新率输出 500 点预存 LFM 波形
- 回波采集：12 位 ADC，采样率 500 kHz，单次触发采集 4096 点
- 数字信号处理：4096 点实数 FFT/IFFT 频域匹配滤波
- 距离分辨率：ΔR = c / 2B = 0.075 m（水中声速 c = 1500 m/s）
- 显示：淘晶驰串口触摸屏（USART1，115200 baud）
- 工作模式：正常测距 / 发射调试 / 接收调试 / 仿真数据验证

## 系统架构

```
DAC → 发射调理（带通 + 双级功放）→ 收发转换 → 收发合一换能器
     → 目标 → 回波 → 接收调理（前置放大 + 偏置）→ ADC → DSP 匹配滤波 → 串口屏
```

## 硬件接线

| 引脚 | 功能 |
|------|------|
| PA4  | DAC1 输出 LFM 发射波形 |
| PA1  | ADC1 回波输入（ADC1_IN1） |
| PA9 / PA10 | USART1（接串口触摸屏或上位机） |
| PF9 / PF10 | 状态指示 LED |
| PC1  | 外部信号源 Sync 输入（EXTI1，上升沿），接收调试时同步触发采集 |

## 算法原理

回波信号与参考 LFM 信号共轭频谱在频域相乘，再经 IFFT 变回时域，等效于时域匹配滤波（脉冲压缩）。对压缩后的包络寻峰，峰值索引 `n` 与目标距离的关系为：

```
d = n · c / (2 · fs)
```

其中 `c = 1500 m/s`，`fs = 500 kHz`。

匹配滤波前置零长度按模式区分：

- 正常/单站（收发合一）：`BLANK_IDX = 600`（1.2 ms），抑制发射期间的电串扰相关峰。
- 接收调试（分置换能器）：`RX_DEBUG_BLANK = 0`（默认不置零），避免误删近距离直达波。

## 串口命令

USART1 @ 115200，命令为 2 字节 `0D + 子码`（HEX 发送）：

| 命令 | 功能 |
|------|------|
| `0D 00` | LED0 闪烁 |
| `0D 01` | 单次测距（发射 LFM 并采集回波，结果发串口屏） |
| `0D 02` | 进入调试模式（占位，无实际动作） |
| `0D 03` / `0D 04` | 发射调试 开始 / 停止 |
| `0D 05` / `0D 06` | 接收调试 开始 / 停止 |
| `0D 07` | 退出调试，回正常模式 |
| `0D 08` + 2 字节 | 设置发射重复周期（ms，16 位小端） |
| `0D 09` | 导出当前一帧原始 ADC（二进制，给 PC） |
| `0D 0B` | 在串口屏页面3显示最近一帧波形（原始包络 + 匹配输出 + 文本） |

> 周期示例（低字节在前）：20 ms = `0D 08 14 00`，100 ms = `0D 08 64 00`，1000 ms = `0D 08 E8 03`。

## 正常测距流程（`0D 01`）

由串口屏页面1的「测距」按钮触发，单次测距的完整流程：

1. **LED1（PF10）闪 5 次**，作为动作提示。
2. **DAC 发一帧 LFM**：`HAL_DAC_Start_DMA` 通过 DMA 输出 500 点 LFM（1 ms）。
3. **启动 TIM2（500 kHz）**：其 TRGO 同时触发 DAC 输出和 ADC 采样。
4. **ADC 采 4096 点**（8.192 ms）写入 `adc_raw`（DMA）。
5. **采集完成回调**：停止 TIM2、置 `adc_complete_flag`、清 `adc_acquiring`。
6. **主循环匹配滤波**：`DSP_RunMatchFilter(..., BLANK_IDX)`，前置零 600 点（1.2 ms）抑制发射电串扰。
7. **结果上屏**：距离换算为毫米，向页面1 的 `x0` 发送 `x0.val=<mm>` + `0xFF 0xFF 0xFF`。
8. **重新武装 ADC DMA**，等待下一次 `0D 01`。

> 说明：`0D 01` 是**单站（收发合一）**逻辑，使用 `BLANK_IDX=600`；只更新页面1 的 `x0`，不更新页面3 的 `v_*`（页面3 用 `0D 0B` 刷新）。每次只测一发。

## 调试模式

### 发射调试（`0D 03`）

TIM2 常开触发 DAC，按 `tx_period_ms` 周期反复发送 LFM 脉冲，便于用示波器稳定观察发射链路（滤波 / 放大 / 功放）输出。周期通过 `0D 08` 设置，`0D 04` 停止。

### 接收调试（`0D 05`）

DAC 静默，由外部信号源（AWG）驱动独立发射换能器，AWG 的 Sync 输出接 PC1。每个 Sync 上升沿触发一次 4096 点采集并做匹配滤波。接收调试期间**不向串口屏发送连续文本**，需要查看时用 `0D 0B` 在页面3按需刷新（见下）。

- AWG 波形须与 `ref_fft_data.h` 参考谱一致（1 ms、195–205 kHz、同调频方向的 LFM）。
- 重复周期设在 AWG 上，需大于采集窗口 8.192 ms，建议 20 ms 起步。
- 分置测试时 DSP 仍按往返 `/2` 计算，显示距离约为两换能器实际间距的一半。

### 原始数据导出（`0D 09`）

将当前 `adc_raw[4096]` 以二进制帧发送，格式（小端）：

```
0xAA 0x55 | len(2 字节, =4096) | 4096 × uint16
```

使用仓库中的 `read_adc_frame.m`（修改顶部 `PORT` 为实际串口号后运行）即可读取一帧、绘制时域波形与频谱，并显示峰值频率和峰峰值幅度。

### 串口屏页面3 波形显示（`0D 0B`）

收到 `0D 0B` 后，单片机把**最近一帧**的原始 ADC 包络与匹配滤波输出下采样为 512 点，发送到串口屏页面3：

| 控件 | 含义 |
|------|------|
| 波形 `s0` | 原始 ADC 包络（每 8 点取 `\|adc-2048\|` 峰值，缩放到 0~255） |
| 波形 `s1` | 匹配滤波（互相关）输出（按本帧峰值归一化到 0~255） |
| 文本 `v_vpp` | 原始时域峰峰值（V） |
| 文本 `v_peak` | 匹配峰索引（0~4095，1 点 = 2 µs） |
| 文本 `v_dist` | 距离（m，DSP 按往返 `/2`） |

- 为保证两条曲线来自**同一完整帧**，`0D 0B` 只置请求标志，等当前采集完成、DSP 跑完后再绘制（`adc_acquiring` 保护）。
- 该操作约需 1.3 s（2 × 512 点），为按需触发，不影响正常采集。
- `s0/s1` 的"数据量"需设为 512。

## 外部电路说明

发射链路需经带通滤波与功率放大以驱动换能器；接收链路经前置放大与直流偏置后送入 ADC。详细电路设计见课程设计报告。
