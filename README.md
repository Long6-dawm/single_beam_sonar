# 单波束声纳测距系统

基于 STM32F407 的单波束声纳测距系统。系统发射线性调频（LFM）脉冲信号，接收水下回波后经频域匹配滤波（脉冲压缩）提取时延，从而实现水下测距，并通过串口触摸屏实时显示距离。

## 技术指标

- 主控：STM32F407VGT6（Cortex-M4F，168 MHz）
- 发射信号：LFM，中心频率 200 kHz，带宽 10 kHz，脉宽 1 ms
- 波形发生：DAC 以 500 kHz 更新率输出 500 点预存 LFM 波形
- 回波采集：12 位 ADC，采样率 500 kHz，单次触发采集 4096 点
- 数字信号处理：4096 点实数 FFT/IFFT 频域匹配滤波
- 距离分辨率：ΔR = c / 2B = 0.075 m（水中声速 c = 1500 m/s）
- 显示：淘晶驰串口触摸屏（USART1，115200 baud）
- 工作模式：真实硬件采集模式 / 仿真数据验证模式

## 系统架构

```
DAC → 发射调理（带通 + 双级功放）→ 收发转换 → 收发合一换能器
     → 目标 → 回波 → 接收调理（前置放大 + 偏置）→ ADC → DSP 匹配滤波 → 串口屏
```

## 硬件接线

| 引脚 | 功能 |
|------|------|
| PA4  | DAC1 输出 LFM 发射波形 |
| PA0  | ADC1 回波输入 |
| PA9 / PA10 | USART1 接串口触摸屏 |
| PF9 / PF10 | 状态指示 LED |

## 目录结构

```
Core/Src/main.c          系统初始化与主循环
Core/Src/dsp_process.c   匹配滤波算法（FFT / 复乘 / IFFT / 寻峰）
Core/Src/adc.c           回波采集配置
Core/Src/dac.c           发射波形发生配置
Core/Src/tim.c           TIM2 触发 / TIM7 节拍
Core/Src/usart.c         串口通信配置
Core/Inc/lfm_data.h      500 点 LFM 发射波形查找表
Core/Inc/ref_fft_data.h  参考信号频域共轭频谱
Core/Inc/test_echo.h     开环测试用仿真回波数据
```

## 算法原理

回波信号与参考 LFM 信号共轭频谱在频域相乘，再经 IFFT 变回时域，等效于时域匹配滤波（脉冲压缩）。对压缩后的包络寻峰，峰值索引 `n` 与目标距离的关系为：

```
d = n · c / (2 · fs)
```

其中 `c = 1500 m/s`，`fs = 500 kHz`。

发射期间（前 1.2 ms）存在发射信号串扰至接收端的现象，程序在预处理阶段将该时段的采样数据置零（`BLANK_IDX`），避免串扰相关峰干扰寻峰。

## 构建

依赖 `arm-none-eabi-gcc` 与 CMake（工程由 STM32CubeMX 生成）：

```
cmake --preset default
cmake --build build/Debug
```

## 使用

- 串口发送 `0x0D 0x00`：LED0 闪烁。
- 串口发送 `0x0D 0x01`：启动一次测距（发射 LFM 并采集回波）。
- 测距结果以 `x0.val=<mm>` + `0xFF 0xFF 0xFF` 发送至串口触摸屏。

## 外部电路说明

发射链路需经带通滤波与功率放大以驱动收发合一换能器；接收链路经前置放大与直流偏置后送入 ADC。详细电路设计见课程设计报告。
